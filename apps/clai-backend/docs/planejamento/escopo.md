# Escopo — CLAI (Fase 1)

## O que o sistema faz

Sistema de apoio à Coordenação Local de Acessibilidade e Inclusão (CLAI) do IFPB Campus Cajazeiras. Nesta fase, permite à equipe administrativa manter o cadastro de estudantes com necessidades educacionais específicas.

## Dentro do escopo

- Login do administrador com e-mail e senha.
- Cadastro, consulta, alteração e exclusão lógica de estudantes.
- Interface web para essas operações.

## Fora do escopo (fase 1)

- Registro de laudos, deficiências e atendimentos. Depende de definição com a CLAI.
- Cadastro de usuários além do administrador.
- Deploy em produção. Será tratado em fase posterior.
